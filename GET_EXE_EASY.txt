# Get Poo AI EXE - 3 Ways

## WAY 1: GitHub Actions (Easiest - No PC Setup!)

### Step 1: Create GitHub Account
- Go to https://github.com/signup
- Sign up with email (takes 2 minutes)

### Step 2: Create Repository
- Go to https://github.com/new
- Repository name: `poo-ai`
- Click "Create repository"

### Step 3: Upload Files
- Click "uploading an existing file"
- Drag & drop ALL files from `poo_ai_assistant_complete` folder
- Click "Commit changes"

### Step 4: Build!
- Click "Actions" tab (top of page)
- Click "Build Poo AI Windows EXE" on left
- Click green "Run workflow" button
- Click "Run workflow" again
- Wait 5-10 minutes (green checkmark = done!)

### Step 5: Download
- Click the completed run
- Scroll to "Artifacts" section
- Download "PooAI-Release-ZIP"
- Extract and double-click PooAI.exe!
